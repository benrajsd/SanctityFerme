Step-by-Step Process

1 Input Collection - CAD Files & Design References

What we receive from the client:

  • CAD files (3D) - building footprints, floor plans, elevations, sections
  • Reference images / mood boards - desired architectural finish, material textures, colors
  • Precise GPS coordinates (lat/long/altitude) for each structure's placement on the globe
  • Any existing renders or visualizations for style reference

2 3D Modelling in Blender / 3ds Max

Import CAD geometry and build complete, textured 3D models:

  • Import CAD footprints and elevations as base geometry
  • Model detailed building geometry (walls, roofs, facades, windows, openings)
  • Apply PBR materials - concrete, glass, metal, cladding - from reference images
  • Set up accurate scale matching real-world dimensions from CAD
  • Add site-level context elements (roads, landscaping, hardscape) if required

3 Multi-Angle Rendering (Render-to-Splat Capture)

Simulate drone photography by rendering from hundreds of virtual camera positions:

  • Place virtual cameras in a grid pattern around each structure at multiple heights
  • Cover 360° horizontal + multiple vertical angles (top-down to horizon-level)
  • Generate 200–500 high-resolution renders per structure with consistent lighting
  • This simulates what a drone photogrammetry survey would capture for a real building

4 Gaussian Splat Generation

Process the renders through Structure-from-Motion and 3D Gaussian Splatting pipeline:

  • Run SfM (COLMAP) on the render set to extract camera poses and sparse point cloud
  • Train 3D Gaussian Splat model on the reconstructed scene
  • Optimize splat density, size, and color for photorealistic output
  • Export splat file (.ply or native format) with local coordinate reference

5 3D Tiles Conversion

Convert the Gaussian Splat to 's streamable 3D Tiles format:

  • Transform local splat coordinates to (lat/long/altitude) using GPS target coordinates
  • Convert splat data to .b3dm or .pnts tile format
  • Generate tile hierarchy (LOD pyramid) for smooth progressive loading
  • Create tileset.json manifest with bounding volumes and geospatial transforms
  • Optimize tile sizes and streaming thresholds for web performance

6 Integration into Globe

Load the new tilesets into the client's live globe application:

  • Upload tile data to client's cloud storage (S3/Azure Blob)
  • Reference new tilesets in the existing application code
  • Configure layer order - new assets sit on top of existing terrain
  • Validate GPS placement accuracy in globe (visual + coordinate check)
  • Tune tile loading thresholds for smooth appearance on zoom-in
  • Test across browsers and devices
